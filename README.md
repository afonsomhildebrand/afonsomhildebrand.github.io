## Publicar no GitHub Pages

1. Crie um repositório público chamado `<seu-usuario>.github.io` (ou qualquer nome, ex.: `cv`).
2. Envie `index.html`, `foto.jpg` e `Curriculo_Afonso_Hildebrand.docx` para a branch `main`.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Em ~1 minuto o site estará em `https://<seu-usuario>.github.io/`.
